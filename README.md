# ml-premium-cost-prediction
Healthcare Premium Cost Prediction
A Machine Learning project that predicts an individual's healthcare insurance premium based on demographic, lifestyle, and health-related factors. The goal is to assist insurance providers and customers in estimating premium costs accurately using predictive analytics.

Project Overview
Healthcare insurance premiums are influenced by several factors such as age, BMI, smoking habits, medical conditions, and region. This project applies machine learning techniques to analyse these factors and predict healthcare premium costs.

The project follows a complete machine learning workflow including:

Data Collection & Exploration
Data Preprocessing
Feature Engineering
Model Training
Model Evaluation
Deployment using Streamlit
Features
✅ Data Cleaning and Preprocessing
